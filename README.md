# Wearable-Health-Insights
Statistical analysis of Fitbit data (via Fitabase).

## About the Data
This project utilizes the **Fitabase dataset**, which consists of minute-level, hourly, and daily physiological records from Fitbit wearable device users.
**Data Source:** [Kaggle: FitBit Fitness Tracker Data](https://www.kaggle.com/datasets/arashnic/fitbit)

## Research Focus 
The repository is structured into multiple research branches to investigate:
- **Part I: Energy Expenditure Estimation**
- **Part II: Advanced Physiological Exploration**
